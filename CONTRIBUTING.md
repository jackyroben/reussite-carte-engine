# Contributing / Contribuer

## English

Open an issue with the expected and actual behavior. For engine bugs, include the deck ID order and move count so another contributor can replay the state. Run `npm test` with Node.js 22 or newer. Exercise interface changes in `demo/index.html` in a browser. Describe the change and the checks in the pull request.

The engine lives in `assets/grid32.js`. Keep presentation and storage in the caller. Preserve card IDs and the save format. By submitting code you agree to contribute it under this repository’s MIT license.

## Français

Décrivez le comportement attendu et celui observé dans un ticket. Pour un défaut du moteur, indiquez l’ordre des identifiants dans la donne et le nombre de coups pour reproduire l’état. Exécutez `npm test` avec Node.js 22 ou plus récent. Essayez les changements d’interface dans `demo/index.html`. Précisez les vérifications effectuées dans la pull request.

Le moteur se trouve dans `assets/grid32.js`. L’interface et le stockage relèvent de l’application qui l’utilise. Conservez les identifiants et le format des sauvegardes. Le code proposé est soumis à la licence MIT de ce dépôt.
